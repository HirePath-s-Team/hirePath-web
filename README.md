# Prep Analytics Suite

Interview preparation with focused questions, structured solutions, and company context.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local dev server
- `npm run build` builds the production bundle
- `npm run preview` serves the production build locally
- `npm run lint` runs ESLint
- `npm run test` runs the test suite

## Tech stack

- Vite
- React
- Tailwind CSS
- shadcn/ui
